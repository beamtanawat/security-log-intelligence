# Project

Security Log Intelligence

## Goal

Build this project incrementally while learning:

- Cybersecurity
- AI and Machine Learning
- Data Engineering
- Software Engineering

## Current Stage

Stage 1 — Basic Security Log Analyzer

## Current Scope

Use only:

- Python
- CSV / JSON security logs
- Basic data analysis
- Basic rule-based detection
- pytest

Do not introduce yet:

- LLM
- Deep Learning
- React
- FastAPI
- PostgreSQL
- Docker
- Kafka

unless explicitly requested.

## Development Rules

- Prefer simple solutions first.
- Preserve raw security log files.
- Never silently modify raw data.
- Keep code readable.
- Explain important design decisions.
- Add tests for important logic.
- Do not over-engineer.

## Learning Rule

When introducing something new:

1. Explain what it is.
2. Explain why it is needed.
3. Implement the smallest useful version.

## Validation

Before finishing a coding task:

- Run relevant tests.
- Check for errors.
- Report files changed.
